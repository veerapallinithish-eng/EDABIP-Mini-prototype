# EDABIP Insights frontend

This React + Vite client provides the authenticated analytics dashboard, data management tools, and user profile settings.

Run `npm install` followed by `npm run dev` from this directory. The Vite client uses `VITE_API_BASE_URL` for both REST and Socket.IO; by default it connects to `http://127.0.0.1:5001`. See the [project README](../README.md) for complete backend/database setup, demo accounts, feature details, and verification commands.

Available checks:

```powershell
npm test
npm run lint
npm run build
```
